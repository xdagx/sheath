# Test-only wallet files for store review / 审核用测试钱包文件

**These keys are public test fixtures. Never send real funds to them.**
**以下密钥是公开的测试数据，切勿向其转入真实资产。**

| File | Format | Password |
| --- | --- | --- |
| this folder: `wallet.dat` + `dnet_key.dat` + `storage/` + `storage-testnet/` | 2018 XDAG C-client wallet folder (3 keys; 7 old mainnet blocks in `storage/`, 1 testnet block in `storage-testnet/`) | `xdag2018` |
| `xdagj/wallet.data` | xdagj wallet v4 (12-word phrase + 3 keys) | `test-password-1` |

**Getting the folder:** on https://github.com/xdagx/sheath click "Code" → "Download ZIP", unzip, and use
`sheath-main/store/reviewer-test-files` (GitHub cannot download a single folder).

Import: welcome tab → "Import a wallet" → set a password → tab "2018 wallet" / "Wallet file".
For the 2018 wallet, "Choose folder" and pick this folder: 8 old addresses are found automatically. None of
them exists on the public networks: on Mainnet the 7 from `storage/` show "Not on this node" and the one
from `storage-testnet/` shows "Other network" (on Testnet it is the other way round).
Once a wallet exists: click the account name at the top left of Home → Import → the same tabs
(in the toolbar popup, use "Open in full page to select files").

导入：欢迎页 →“导入钱包”→ 设置密码 →“2018 旧钱包”/“钱包文件”页签；已有钱包时：点击首页左上角的账户名 →“导入”。
获取文件夹：在 https://github.com/xdagx/sheath 点 “Code → Download ZIP”，解压后使用 `sheath-main/store/reviewer-test-files`。
2018 旧钱包可点“选择文件夹”并选中本文件夹，会自动找到 8 个旧地址；它们都不在公网节点上：主网下 `storage/` 的 7 个显示“节点上无记录”、`storage-testnet/` 的 1 个显示“其他网络”，测试网下相反。
The files were generated by the original XDAG C code and by xdagj itself (see `tools/vectors/`);
`storage/` was written by the C client's own `xdag_storage_save()` and includes three damaged files on purpose.
